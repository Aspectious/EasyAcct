# EasyAcct 
## An easy way to handle bank accounts!
(Also my final for my CSCI 1620 Course)


Dependencies
- While able to run with a .db file, if you are seeking to connect to a MySQL or MariaDB Server, Please install the following packages:
  
  mysql-connector-python
  
  Pip:
  `pip install mysql-connector-python`

For anyone questioning this project's legitimacy, yes I did write this myself with lots of time, effort and some documentation reading, especially for the Qt Framework. I have had prior experience writing full stack SQL applications (Check my GitHub!), so it was a fun exercise to apply it to the Qt framework.
Here's a list of documentation, sites, and programs which have helped this project's development.

- Qt for Python 6 Documentation https://doc.qt.io/qtforpython-6
- Python Documentation on Sqlite3: https://docs.python.org/3/library/sqlite3.html
- MySQL's Python driver/connector: https://dev.mysql.com/doc/connector-python/en/
- Pycharm / Datagrip (So helpful having the database as a mutable table)
